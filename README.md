# Трекер здоровья в Telegram

Личный бот для учёта питания, воды, веса, задач и приёма таблеток. Работает для одного владельца.

## Возможности

- Нормы калорий, БЖУ и воды по формуле Миффлина — Сан Жеора, прогноз даты цели.
- Распознавание фото еды, весов и часов через Gemini с подтверждением перед записью.
- Таблетки: расписание, повтор напоминания, журнал приёмов, остаток в упаковке.
- Задачи: разовые, ежедневные и по дням недели, перенос невыполненного.
- Напоминания с кнопками, утренняя и вечерняя сводка.

Бот не даёт медицинских рекомендаций и не заменяет врача.

## Устройство

- `bot/handlers/`: обработка сообщений и кнопок.
- `bot/scheduler.py`: фоновый цикл. Его состояние лежит в базе, поэтому после перезапуска напоминания не теряются.
- `bot/repo.py`: запросы к SQLite.
- `bot/nutrition.py`, `bot/parsing.py`: чистые функции расчётов и разбора текста.
- `bot/gemini.py`: сменный модуль распознавания.

## Настройка `.env`

| Переменная | Обязательна | Значение |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather |
| `ALLOWED_USER_ID` | да | свой Telegram ID, можно узнать у @userinfobot |
| `TIMEZONE` | нет | часовой пояс, по умолчанию `Europe/Moscow` |
| `GEMINI_API_KEY` | для фото | ключ из Google AI Studio |
| `GEMINI_MODEL` | нет | по умолчанию `gemini-3.5-flash` |
| `GEMINI_PROXY` | нет | прокси, если Gemini недоступен напрямую |

## Запуск

Локально:

```zsh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
python -m pytest
python -m bot.main
```

На сервере:

```zsh
docker compose up -d --build
docker compose logs -f bot
```
